# 🎙️ Voxcribe — Bangla & Multilingual Speech to Text

Fast, accurate AI transcription powered by **faster-whisper** on **Hugging Face ZeroGPU**.

## Features
- Bangla, English, Hindi, Arabic, Spanish speech recognition
- Multiple Whisper model sizes (large-v3, turbo, medium, small, base)
- Transcription & Translation to English
- SRT subtitle export
- Microphone & file upload support
